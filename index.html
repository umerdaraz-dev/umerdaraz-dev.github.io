    DHA Quetta, housing authority, Pakistan

    Odoo ERP for a housing authority: property, allotment and land management

    The situation

    The authority runs membership, plot allotment, transfers, building approvals and land acquisition for a large housing scheme. Every process has its own stages, approvers and fees, and the custom modules had to move from Odoo 16 to 19 without stopping daily work.

    The flow

    1. Property bank
    2. Membership
    3. Allotment or ballot
    4. Transfer
    5. Building approvals

    What I built

    • Batch allotment: one case allots several properties to one buyer, and all of them move through the approval chain together.
    • A computerised location ballot with encrypted entries, role-based access and a public reveal screen, with PDF and Excel results.
    • Land acquisition: land providers, ownership records by revenue-estate identifiers, possession and file delivery. I removed its dependency on Enterprise Documents so it runs on Community.
    • The upgrade of the custom suite from 16 to 19: views, ORM calls, access rules and JavaScript.
    • An API that receives records pushed from the legacy Oracle system, validates them and creates or updates them in Odoo.

    Stack

    • Odoo 16
    • Odoo 19
    • Python
    • PostgreSQL
    • QWeb
    • REST API
    • OWL
